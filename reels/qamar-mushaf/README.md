# Qamar — рилс «Мусхаф»

`qamar-mushaf.mp4` — 1080×1920, 30 fps, 29 с, H.264 bt709 + AAC 192k, −14 LUFS. Без голоса и музыки — синтезированные SFX.
Обложка: `cover.jpg` (кадр 10.6 с), подпись: `caption.txt`.

## Факты и источники
- Все экраны — реальные скриншоты Qamar с iPad (`src/raw/`), 18 окт. 2026. Обрезаны статус-бар и верхняя панель.
- Аят — аль-Фатиха 1:6; перевод на казахский из приложения: Анарбаев Нұрлан, Әкімханов Асқар.
- Чтец в плеере — Mohamed Siddiq El-Minshawi (как в приложении).
- Показаны только функции, видимые на скриншотах: таджвид-раскраска, карточка аята (транскрипция, перевод, избранное,
  закладка, заметка, поделиться), аудио с подсветкой аята, ночная тема, заметки.

## Цвета

(линза таджвида; золотая черта под аятом в приложении).

## Пересобрать (из `src/`)
```
python3 tools/prep_shots.py          # raw/*.png → web/shots/*.jpg
python3 sfx.py                       # web/timeline.json → mix.wav
node render.mjs --stills 5.8,10.6,15,19.5,23.5 && python3 tools/sheet.py stills sheet.jpg
node render.mjs ../qamar-mushaf.mp4 30
```

## Чего нет (ограничения окружения)
- Озвучки ElevenLabs: нет ключа `ELEVENLABS_API_KEY`, домен `api.elevenlabs.io` не разрешён в сети окружения.
- Съёмки qamar.web.app в облаке: домен `qamar.web.app` не разрешён — поэтому используются скриншоты с iPad.
